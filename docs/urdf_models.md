# URDF model preparation

## Purpose

The files in
`ros2_ws/src/nonsequential_task_description/urdf/` were used to import visible
UR3e and UR5e models into CoppeliaSim:

- `ur3e_visible_mesh.urdf`
- `ur5e_visible_mesh.urdf`

They are preparation artifacts, not replacements for the runtime robot
description generated by the Universal Robots ROS 2 Driver.

## Original import problem

URDF files generated from `ur_description` referenced meshes with ROS package
URIs such as:

```text
package://ur_description/meshes/ur5e/visual/base.dae
```

CoppeliaSim's direct URDF importer did not resolve `package://ur_description`,
so the joints appeared but the visible robot geometry was missing.

## Validated fix

The package prefix was replaced with the absolute installed package URI:

```text
file:///opt/ros/humble/share/ur_description
```

For example:

```text
file:///opt/ros/humble/share/ur_description/meshes/ur5e/visual/base.dae
```

The included URDF files already contain this form and are ready for an Ubuntu
22.04 / ROS 2 Humble installation in the standard `/opt/ros/humble` location.

Check that every referenced local mesh exists:

```bash
export ROS_DOMAIN_ID=7
source /opt/ros/humble/setup.bash
source "$HOME/ur_ws/install/setup.bash"

test -d /opt/ros/humble/share/ur_description/meshes \
  && echo "OK: ur_description meshes found"

rg -o 'file://[^" ]+' \
  "$HOME/zavrsni_nonsequential_task_execution/ros2_ws/src/nonsequential_task_description/urdf"/*.urdf \
  | sort -u
```

## Recreate the path conversion

If a fresh URDF has already been generated with xacro, convert its mesh prefix
without changing the source package:

```bash
export ROS_DOMAIN_ID=7
source /opt/ros/humble/setup.bash
source "$HOME/ur_ws/install/setup.bash"

mkdir -p "$HOME/ur_models"

sed \
  's#package://ur_description#file:///opt/ros/humble/share/ur_description#g' \
  "$HOME/ur_models/ur5e_generated.urdf" \
  > "$HOME/ur_models/ur5e_visible_mesh.urdf"
```

Use the same command with the UR3e filenames. The xacro-generation command can
vary with the installed `ur_description` version; use the launch/xacro
arguments from the installed Universal Robots driver and apply only the URI
conversion shown above.

## Import into CoppeliaSim

1. Start CoppeliaSim from a terminal with the ROS 2 Humble environment sourced.
2. Use the URDF import function and select the prepared URDF.
3. Confirm that all six joints and all visual meshes appear.
4. Keep the imported model kinematic for this project unless its dynamics have
   been deliberately configured and validated.
5. Rename or preserve the object paths expected by the embedded Lua scripts.
6. Save the scene as a new copy before changing the validated scenes.

The current dual-UR scripts expect the scene objects and joint paths encoded in
their corresponding `.lua` files. Renaming imported objects without updating
the scripts causes `sim.getObject` failures.

## Portability note

The absolute `/opt/ros/humble` paths are intentionally specific to the tested
platform. On another ROS distribution or non-standard installation, replace
that prefix with the output of:

```bash
ros2 pkg prefix ur_description
```

Do not commit generated URDF files that reference a user's home directory.
