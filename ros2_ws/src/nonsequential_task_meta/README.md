# Non-sequential task metapackage

This metapackage groups the custom ROS 2 packages developed for the thesis:

**Non-sequential Task Execution with Two Industrial Robots**

## Included packages

- `nonsequential_task_bringup` – namespaced dual-UR launch and configuration files
- `nonsequential_task_control` – forward-position bridges and recorded JointTrajectory execution
- `nonsequential_task_description` – robot-description files used during model preparation
